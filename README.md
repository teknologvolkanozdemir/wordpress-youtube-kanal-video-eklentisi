# WordPress YouTube Kanal Video Eklentisi

YouTube kanallarındaki yeni videoları WordPress yazısı olarak yayımlar ve videoların
WordPress sitenizde oynatılmasını sağlar.

## Kurulum

1. `wordpress-youtube-kanal-video-eklentisi.php` dosyasını
   `wp-content/plugins/wordpress-youtube-kanal-video-eklentisi/` klasörüne yükleyin.
2. Eklentiyi WordPress yönetim panelindeki **Eklentiler** sayfasından etkinleştirin.
3. **YouTube Kanalları** menüsünü açın; kanal bağlantısını ve videoların ekleneceği
   kategoriyi seçip kanalı ekleyin.

Her kanal için bir kategori seçilebilir ve istenildiği kadar kanal eklenebilir.
Eklenti kanalları saatte bir kontrol eder; **Kanalları şimdi kontrol et** düğmesiyle
elle de kontrol başlatılabilir. Yeni videolar, oynatılabilir YouTube gömmesiyle
WordPress'te yayımlanır. Aynı video birden fazla kez içe aktarılmaz.
